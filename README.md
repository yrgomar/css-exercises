# CSS Exercises

This repository contains CSS exercises from **The Odin Project**. Each exercise focuses on a specific layout or styling concept.

## Purpose

- Practice core CSS concepts through small, focused exercises.
- Learn how different CSS properties affect layout and appearance.

## What I Did

- Completed the exercises exactly as described in The Odin Project curriculum.
- Applied selectors, colors, spacing, alignment, and basic layout patterns.
- Tweaked CSS to match the expected designs as closely as possible.

## Skills Practiced

- CSS selectors and specificity.
- Margin, padding, borders, and box model.
- Text styling and basic layout techniques.
- Using external stylesheets in HTML projects.
